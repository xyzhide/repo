# site-build — SITETECH 制作手順

前提: `CLAUDE.md` の「絶対に守ること」を必ず守る。sitetech.jp 本体には触れない。

## 手順

1. **目的と対象を一行で確認する。** 何を、どのページ・どの機能に対して行うかをユーザーに確認する。曖昧なら実装せず質問する。
2. **前提を読む。** `CLAUDE.md`、`feature_list.json`、`claude-progress.txt` を読み、現状と未完了項目を把握する。
3. **計画を書く。** 変更するファイル、変更内容、確認方法を箇条書きにする。前提に不安があれば `advisor` に確認する。
4. **1機能だけ実装する。** 複数機能をまとめて進めない。
5. **lint / build を実行する。** 定義されているものだけ実行する（`package.json` に `lint` / `build` があれば）。失敗したら直してから次へ進む。
6. **表示・動作を確認する。** ページなら該当ページを確認し、確認した事実（何を見て何が正しかったか）を書く。
7. **ユーザーの確認を得る。** 確認を得てから `feature_list.json` の該当項目を完了にし、`claude-progress.txt` に追記する。
8. **次の機能へ進む。** 手順2に戻る。

## 禁止事項

- sitetech.jp 本体への変更・デプロイ・設定変更
- 外部送信、公開、メール送信（ユーザーの明示的な指示と確認が必要）
- 実績・数字・価格の推測による記載（根拠が無いものは「要確認」と書く）
- 秘密情報（キー、パスワード、トークン）をファイルに書くこと

## 完了の報告

完了と言ってよいのは、確認した事実がある場合だけ。「ファイルを作った」だけでは完了ではない。
